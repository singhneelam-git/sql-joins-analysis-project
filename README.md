# sql-joins-analysis-project

Overview

This project demonstrates the use of SQL joins to analyse customer and order data. It focuses on understanding customer behaviour, revenue distribution, and identifying customers without transactions.

Tools

SQL (SQLite)


Analysis Performed

Inner join between customers and orders
Revenue calculation per customer
Revenue by city
Identification of customers without orders using LEFT JOIN


Key Insights

Neelam is one of the highest spending customers
London generates high revenue
Some customers have no orders (data gap identified)
Laptop is a major revenue-generating product


Skills Demonstrated

SQL JOINs (INNER & LEFT)
Aggregations (SUM, GROUP BY)
Business data analysis
